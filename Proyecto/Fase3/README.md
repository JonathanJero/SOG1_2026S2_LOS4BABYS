# Fase 3 - Integracion, Pruebas y Analisis Final (TechCore Solutions)

Esta carpeta reune la planificacion, documentacion tecnica consolidada, manuales por integrante, tareas asignadas, artefactos de Business Intelligence y videos demostrativos de la Fase 3 del proyecto.

## Donde esta el Sistema Odoo y la Base de Datos

El servidor central de Odoo, Docker Compose, los respaldos y scripts de arranque se encuentran unificados en:
`Proyecto/techcore-odoo/`

Para iniciar el entorno:
- En Linux / macOS: `cd ../techcore-odoo && ./start.sh`
- En Windows PowerShell: `cd ..\techcore-odoo ; .\start.ps1`
